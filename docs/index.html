The gate, in the same order every time

Most mistakes in halal investing are not hard cases. They are a bond fund inside a tax wrapper nobody screened, a savings account chosen for its rate, a clean company whose job is in its defence unit, or a single screener's green tick taken on trust. Tayyib runs the same procedure every time and writes the same document.

  1. Core business firstBanking, insurance, gambling, alcohol, defence and whatever serves them. A fail here is a FAIL whatever the ratios. For a job, the unit and the work, not just the group.
    Source: the annual report's segment note, the unit's page, the job description.
  2. The three ratiosNon-compliant income below 5% of revenue; debt below 33% of market capitalisation; cash and interest-bearing securities below 33%.
    Source: the latest filing and exchange data, with the basis stated.
  3. Two sources must agreeScreener pages are fetched and dated. A split is BORDERLINE at best. A page that cannot be read is "unverified" and does not count.
    Source: the two primary screeners and a tiebreaker.
  4. One verdict in a fixed layoutCLEAN, BORDERLINE or FAIL, with the reasoning, the purification arithmetic and a re-screen date. A checker fails any verdict that drifts from the layout.
    Eight numbered sections, a mark on every fact, footnoted sources at the end.
✅ CLEAN

Passes core business and the three ratios, and two independent sources agree on pages read today.

🟡 BORDERLINE

Means borderline. A split or unverified source, a ratio near its limit, a fund with no purification policy. The verdict names what resolves it.

❌ FAIL

A core-business fail or a ratio over its limit. Never softened for yield, pay or convenience.

What it screens

Stocks

Core business, then the three ratios, then two screeners agreeing. The interest-income percentage is reported even when it passes.

Funds

CLEAN only for a fund screened to a named Shariah index or methodology with a Shariah board. Any fund holding bonds is a FAIL.

Cash and savings

Conventional interest is riba. Prize-draw savings are riba and gambling. CLEAN: Islamic-bank products on an expected-profit basis under a Shariah board.

Wrappers: ISAs and pensions

The wrapper is neutral; every holding inside it is screened. A default pension fund is usually conventional and a FAIL until changed.

Employers and clients

Core-business test on the company, then on the unit and the work itself. A clean company's defence or lending unit is a FAIL for a role in it.

Install it in your agent

Pick your agent. Two minutes, no account.

One line, as a plugin. The skill then answers to /tayyib.

/plugin install tayyib --marketplace me2resh/tayyib

Older versions: /plugin marketplace add me2resh/tayyib, then /plugin install tayyib@tayyib. From a shell: claude plugin install tayyib --marketplace me2resh/tayyib.

Codex reads skills from ~/.codex/skills. The installer copies the folder there.

git clone https://github.com/me2resh/tayyib
cd tayyib
./install.sh codex

Cursor uses project rules. Copy the rule file and the skill folder into your project.

git clone https://github.com/me2resh/tayyib
mkdir -p .cursor/rules
cp tayyib/.cursor/rules/tayyib.mdc .cursor/rules/
cp -R tayyib/skills/tayyib .cursor/

Copilot reads repository instructions. Copy the instructions file and the skill folder.

git clone https://github.com/me2resh/tayyib
mkdir -p .github
cp tayyib/.github/copilot-instructions.md .github/
cp -R tayyib/skills/tayyib .github/

Any agent that reads a folder with a SKILL.md, or a plain instructions file.

git clone https://github.com/me2resh/tayyib
cd tayyib
./install.sh /path/to/your/agent/skills

Then ask the way you would ask a colleague.

  • Is Acme halal?
  • Screen this fund before I put it in my ISA.
  • Can I take this role? The company is clean but the job is in the lending unit.
  • Purification owed on 500 shares held all year.

Five things it will not do

  • Soften a verdict for yield or pay.Pay, yield, convenience and urgency never enter the verdict. The screen gives evidence; the person decides.
  • Take one screener's tick.Two independent sources must agree. A split is BORDERLINE at best, with the failing ratio named.
  • Turn unverified into clean.A page that cannot be read, a fund with no stated methodology, a product that cannot be classified: the answer is BORDERLINE with the reason.
  • Leave a verdict undated.Ratios move with price and with each quarterly filing. Every verdict carries a re-screen date or trigger, and a verdict older than its date is not a verdict.
  • Record what the person holds.A verdict is about the product, not the person. No balances, holdings or employer in the skill's files.
